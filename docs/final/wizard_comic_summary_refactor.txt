WIZARD COMIC COLLECTED DISPLAY

The Comic Collected presentation uses one widget scene:
  widgets/wizard_comic_summary.tscn

The scene contains 11 conditional chapter cover nodes. Each node is selected
directly from the wizard_comic_summary_show event's chapter_number value (1
through 11). Each chapter node contains the matching cover and title-overlay
artwork.

Flow:
  chapter wizard summary -> wizard_comic_summary_show with chapter_number ->
  3-second Comic Collected presentation -> hide.

There are no chapter-specific Comic Collected widget_player events.
