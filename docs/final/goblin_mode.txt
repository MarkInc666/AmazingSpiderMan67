GREEN GOBLIN - CHAOS MULTIBALL
===============================

START
-----
- The intro-held saucer ball is released before Ball 2 is served.
- Green Goblin starts as a two-ball multiball.
- Chaos Value starts at 500K, never resets, has a 100K minimum, and has no maximum.
- The mode ends when multiball returns to one ball in play.

SIX LOGICAL SHOTS
-----------------
1. Left web
2. Center/right web
3. Left pop
4. Right pop
5. Left drop-target bank
6. Right drop-target bank

Any individual drop-target hit counts as the logical shot for that bank. A completed
bank still resets normally.

UNSAFE PHASE
------------
- General illumination is red.
- All six shots are solid.
- The three saucers are lit to collect Chaos Value and begin Safe play.
- Each bad shot scores 20K immediately and removes 100K from Chaos Value.
- Chaos Value cannot fall below 100K.

SAUCER COLLECT AND HOLD
-----------------------
- When Green Goblin is not already holding a ball, a ball entering any saucer scores
  the current Chaos Value and adds it to the CHAOS SCORED summary total.
- Collecting does not reset or reduce Chaos Value.
- That ball remains held while the other ball plays the Safe phase.
- Only the first occupied Goblin saucer can collect and hold a ball.

SAFE PHASE
----------
- General illumination turns green and the six shots flash.
- Each logical shot can be made once per Safe phase.
- A good shot scores 100K immediately and adds 100K to Chaos Value.
- More JP changes the immediate good-shot score to 150K.
- Bigger JP changes the Chaos Value increase to 150K.
- Safe lasts 10 seconds, or 15 seconds with the More Time case file.
- Completing all six shots ends Safe early.

At the end of Safe, MORE CHAOS! appears immediately. The held saucer is released,
and the mode waits for its switch to become inactive before returning to Unsafe.
If the switch remains active, Green Goblin makes one additional release request after
650 milliseconds. The next unheld saucer entry can then collect the current value and
start another Safe phase.

HELD AND SECOND-SAUCER BEHAVIOR
-------------------------------
- Repeat switch chatter from the held saucer is ignored.
- If the held switch becomes inactive unexpectedly, the false hold is cleared and
  the mode returns safely to Unsafe play.
- If the other ball enters a different saucer while a Goblin ball is held, it scores
  50K, plays the rejection response, and ejects after 750 milliseconds.
- A second saucer entry does not collect Chaos Value and does not change the Safe timer.

MESSAGES
--------
- Temporary scoring messages use latest-message-wins behavior, so rapid hits cannot
  create a stale message backlog.

CASE FILES
----------
- More JP: good shots score 150K immediately.
- Bigger JP: good shots add 150K to Chaos Value.
- More Time: Safe lasts 15 seconds.
- Ball Save: starts a 10-second ball save after the first held-ball release.
- Safety Net: the first good shot in each Safe phase awards one additional ball.

SUMMARY
-------
- ATTACK TOTAL: immediate good, bad, and second-saucer shot scoring.
- CHAOS SCORED: total Chaos Value collected at saucers.
- POINTS: the mode's complete score contribution.
