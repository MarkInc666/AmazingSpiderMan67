ASM67 ON-MACHINE TEST MODE HARNESS
==================================

Purpose
-------
A disposable hardware-only test session for the 67 story modes:
55 villains + 11 chapter wizards + Final Showdown.
It does not attempt to preserve or rejoin normal campaign progression.

Entering the harness
--------------------
While ATTRACT is running, enter this flipper sequence within 5 seconds:

    LEFT LEFT RIGHT RIGHT LEFT RIGHT LEFT RIGHT

Then press START normally. The new game opens TEST MODE SELECT instead of
normal chapter/villain progression.

To disarm the harness from ATTRACT:

    RIGHT RIGHT LEFT LEFT RIGHT LEFT RIGHT LEFT

The attract flag is a non-persistent machine variable, so a power cycle also
returns the machine to normal gameplay.

Attract start feedback
----------------------
If START is pressed before all six balls have returned to the trough, MPF keeps
the game in attract mode while its normal collection or ball-search process
continues. A four-second WAITING FOR BALLS widget explains why the game did not
start. Pressing START again refreshes the message; a successful game start
removes it immediately.

Mode selector controls
----------------------
LEFT / RIGHT flipper release  = previous / next mode
BOTH flippers                 = enter setup

Selection 68 is EXIT TO ATTRACT. Press START on that selection to disarm the
test harness, skip the normal end-of-ball bonus, end the disposable test game,
and return to attract mode. The next press of START begins normal gameplay
unless the attract-mode enable code is entered again.

Villain setup
-------------
LEFT / RIGHT = choose More Jackpots, More Time, Bigger Jackpots, Safety Net,
               Shot Assist, or BACK
BOTH         = toggle the highlighted Case File, or use BACK
START        = start the highlighted villain with exactly those Case Files

The five test Case File choices are retained between test launches during the
same test game.

Wizard / Final Wizard setup
---------------------------
LEFT / RIGHT = adjust chapter Case File total from 0 through 25
BOTH         = back to the mode list
START        = start the highlighted wizard with that total

The harness writes chapter_case_files_collected and the existing derived
mini_wizard_case_file_bonus / mini_wizard_jackpot_value values, so wizard
scoring uses the same Case File bonus path as normal play.

Test-session flow
-----------------
The attract machine flag is armed before the disposable game begins.
villain_progression is the only campaign coordinator that examines the original
ball_started edge. It decides whether the ball belongs to a normal game or a
test session. Normal games then receive a separate normal_game_ball_started
event; campaign-only modes (chapter select, villain qualification, villain
saucer-start handling, Case File qualification and the normal skill shot) start
from that event instead of ball_started. Test sessions never receive it. Daily
Bugle Mystery and Extra Ball now receive a separate test_mode_support_started
edge so their shared switch SFX, VUK/award support and ball-save presentation
remain available without booting normal campaign progression. The test branch
also clears the new-player chapter-select
flags before opening TEST MODE SELECT. This removes the chapter/qualification
race entirely rather than relying on same-event conditional mode starts.

Selected villains and wizards are not test-aware. The harness/progression layer
sets up the disposable player state and then uses each mode's normal intro/start
events. The gameplay mode runs the same code path it uses in a normal game.
Test summaries are still shown. After a summary, the harness disables the
flippers and autofire coils so any live ball drains. The test-session ball save
protects only the last ball, preventing ball_ending and the end-of-ball bonus,
then serves that ball back to the mechanical shooter lane. TEST MODE SELECT
reopens after the replacement reaches the shooter lane and leaves the ball
parked there while the player chooses the next test. Pressing START launches the
selected villain/wizard through its normal intro; 250 ms after that intro ends,
the harness pulses the auto-plunger if the shooter-lane switch is still active.
The shooter-lane switch is never used as a tester command. Multiball drains above
one ball are not saved, so multiball modes still reduce normally. If the harness
last-ball save fires while a multiball device is still active, progression does
not treat that save as a failed test attempt; the tested mode owns its normal
multiball-ended behavior. Outside active multiball, a last-ball drain during an
active test resolves that attempt as a failed/ended mode, shows its normal
summary, and uses the same return loop.

Normal skill shot and the normal plunge ball save are suppressed for the entire
test session. Mode-specific ball saves remain active so their behavior can still
be tested. While TEST MODE SELECT is active, its START-button handler vetoes
MPF's normal Ball-1 add-player request; START therefore belongs exclusively to
the harness on that screen.

TEST HARNESS V3 - STRICT STARTUP ISOLATION

The test game still uses a real MPF player/ball context, but raw ball_started is reserved for infrastructure only.
Normal campaign/background gameplay is now bootstrapped exclusively by normal_game_ball_started, which villain_progression posts only for non-test sessions.

Moved behind normal_game_ball_started:
- chapter-select automatic startup
- villain qualification
- villain saucer-start handling
- Case Files
- normal skill shot
- Bonus Lanes background mode
- Chaos Pops background mode

Still allowed on raw ball_started because tested modes depend on the infrastructure:
- base scoring/device support
- light feedback
- music control
- villain bookends
- villain progression/test harness owner

Started only by test_mode_support_started during a harness game:
- Daily Bugle Mystery (shared upper-playfield SFX and normal disable/enable path)
- Extra Ball (ball-save count/widget/SFX, SHOOT AGAIN lamp and Daily Bugle extra-ball VUK ownership)

The selected villain or wizard remains unaware of test mode.
