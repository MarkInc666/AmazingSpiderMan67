VULTURE — SKY ATTACK

Core flow
- Vulture opens the rooftop gate for the duration of the mode.
- The 40-second mode timer starts on the first upper-playfield entry.
- If add-a-ball multiball is active when time expires, the mode continues until multiball ends.
- If multiball is not active at time expiry, the mode ends immediately.

Upper targets
- Each upper target starts at pulsing YELLOW and lights pulsing RED when hit.
- Every target hit scores 50K.
- Each red target has its own eight-second timer. Re-hitting that target restarts
  only its timer. When its timer expires, it returns to yellow.
- More Time increases each individual timer to twelve seconds.
- Shot Assist makes the first upper-target hit light all three targets red.
- When all three targets are red, the next upper-target hit awards the one-time
  add-a-ball. If any target returns to yellow first, add-a-ball is no longer ready.

Spinners
- After the first rooftop entry starts the mode timer, both the upper and lower
  spinners score the combined value of all three target stages:
  YELLOW 20K / RED 50K.
- Bigger Jackpots doubles stage values to 40K / 100K.
- Two balls on the upper playfield doubles the total spinner value again.
- More Jackpots adds 100K per spin while all three targets are red.
- Spinner scoring from either spinner is also banked into vulture_bonus for
  end-of-ball bonus.

GI
- Base/lower-playfield GI is yellow.
- Upper-playfield entry changes GI to blue 4080F0.
- Either upper exit or the middle-right A rollover returns GI to yellow.
- Normal GI control is restored when Vulture ends.
