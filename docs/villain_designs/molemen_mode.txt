THE MOLEMEN — FINAL MODE DESIGN

CORE
- Start a 2-ball multiball.
- Opening multiball save is 15 seconds, or 25 seconds with Safety Net.
- There is no overall mode timer.
- Rooftop gate remains closed for the entire mode. Gate-open requests are ignored, and normal gate control returns when the mode stops.
- End the mode immediately when Molemen multiball ends. There is no one-ball grace after MPF has ended the multiball device.
- Playing the mode counts as completion when it ends.

AREAS AND SAUCERS
- Left pop -> Saucer 1.
- Center web target -> Saucer 2.
- Right pop -> Saucer 3.
- Both drop banks reset at mode start and whenever a bank is completed.
- Left pop, center web, and right pop remain lit as the three build zones.
- One area hit lights its matching saucer jackpot.
- Pop hits score 50K, or 75K with Bigger Jackpots.
- Center web hits score 100K, or 150K with Bigger Jackpots.
- With Shot Assist, the left web target always counts as the center web target and awards the same score/progress.

ADD-A-BALL
- Left and right pops require 3 hits to qualify add-a-ball at their matching saucer.
- With More Jackpots, the pop requirement is 2 hits.
- Center web requires only 1 hit for both jackpot and add-a-ball qualification.
- Add-a-ball can be awarded only once per saucer per mode.
- Each add-a-ball starts a 10-second shoot-again save, or 15 seconds with More Time.
- After a saucer has used add-a-ball, later jackpots at that saucer still work normally.
- While add-a-ball is ready, the matching green 1, 2, or 3 insert stays solid and the red saucer-hole lamps flash. Collection resets the numbered insert with the area.

JACKPOTS
- Jackpot value is 250K multiplied by balls currently in play.
- With Bigger Jackpots, value is 300K multiplied by balls currently in play.
- Collecting a jackpot resets that area to 0 progress and turns its saucer light off.
- The add-a-ball-used flag does not reset.
