ASM67 END-OF-BALL BONUS

The upper score panel continues to show the current player's overall score
throughout the bonus count. Its title uses the current player number and reads
PLAYER 1 SCORE, PLAYER 2 SCORE, PLAYER 3 SCORE, or PLAYER 4 SCORE. The player
number comes from the same delayed Bonus entry update as the count, avoiding a
stale Player 1 label during later players' bonuses.

The Bonus slide uses the same purple spiderweb background as Attract. The center
panel shows the current count item. A persistent lower panel displays the
current-ball running total:

BONUS TOTAL
<current regular and mode bonus>

Regular bonus lamps count once from low to high. If a multiplier is active, the
2X through earned-X lamps then count once each. Every multiplier step adds one
copy of the base regular-bonus subtotal without replaying the regular lamps.

Mode bonuses follow and add to the same running total. At the end of the
current-ball sequence, the center panel displays:

TOTAL BONUS
<current regular and mode bonus>

A carried Held Bonus is deliberately excluded from BONUS TOTAL and TOTAL BONUS.
It is presented afterward as a separate HELD BONUS and added directly to the
player's score. This keeps a previous held value separate if the current bonus
is held again.

When Hold Bonus is earned before the last ball, the current total is banked for
the next ball, the lower running-total panel changes to BONUS HELD, and a carried
Held Bonus is still paid separately. Only the current running total is banked.

On the last ball, a newly earned Hold Bonus cannot be banked. It is paid as a
separate HELD BONUS without changing the displayed current-ball running total.
If a carried Held Bonus also exists, the carried and newly earned values are
shown and paid as separate HELD BONUS entries.

The final total remains on screen for the existing 2.5-second hold.
Machine testing remains required.


FINAL SHOWDOWN RETIREMENT CASH-OUT
----------------------------------
When a player completes Final Showdown, the current physical ball still drains and
the normal end-of-ball Bonus sequence runs. Before TOTAL BONUS, the retiring player
receives BALLS REMAINING at 10,000,000 points for each future ball that is being
forfeited: unused normal balls plus all earned extra balls still queued.

The Final Showdown completion ball itself is not counted. If Hold Bonus was earned,
the Final Wizard completion is treated as the player's effective last ball so the
held value is awarded now rather than banked for a turn that will never occur. The
remaining-ball cash-out is added after Hold Bonus so it is not doubled by Hold Bonus.

After Bonus, all queued extra balls for the retired player are consumed. If another
non-retired player still has a normal ball remaining, play rotates to that player.
If no eligible player remains, player_retirement calls MPF's explicit game.end_game()
so the normal game_will_end -> game_ending -> game_ended / high-score path runs.

September 9, 2026 correction: player_retirement now survives every ball and
disables flippers/autofire as soon as Final Showdown multiball ends at one ball
in play. The last physical ball drains into the normal Bonus sequence, where
BALLS REMAINING awards 10,000,000 per unused normal or earned extra ball.

After TOTAL BONUS, the retiring player receives a five-second full-screen ending:
YOU'VE REACHED THE END / KINGPIN DEFEATED / FINAL SCORE. Bonus keeps its wait
queue until this screen completes, so another player or attract cannot start
underneath it.
