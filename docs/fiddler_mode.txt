FIDDLER MODE

STATUS
Implemented to the August 25, 2026 reviewed rules. Requires physical-machine playtesting for saucer hold/release timing, note readability, and the failure/retry flow.

CORE GAMEPLAY
- Fiddler is a saucer-started Simon Says / musical-memory mode. The saucer ball
  that selected and started Fiddler remains held after the intro and immediately
  begins the first WATCH phase; it is not ejected by the shared villain startup.
- If Mystery starts Fiddler from the Daily Bugle VUK, Fiddler cancels the normal
  Mystery eject, holds that VUK ball through the first WATCH playback, then fires
  the VUK for REPEAT.
- The four note shots are:
  1. Left Web = violin note 1
  2. Left Bank Rubber = violin note 2
  3. Right Pop = violin note 3
  4. Right Bank Rubber = violin note 4
- Left and right drop targets are forced down during the mode so the bank rubbers remain available.
- All three saucers pulse white (FFFFFF) while Fiddler is waiting for the player to start/restart a round.
- The four note-shot indicators alternate bright green 40FF40 and dim green
  208020 during WATCH and note feedback.
- Entering any saucer holds the ball during WATCH and ejects that same saucer only when YOUR TURN begins. The first pattern therefore remains physically held in the saucer for the full WATCH presentation.

WATCH PHASE
- Each note alternates 40FF40 for 200ms and 208020 for 100ms, repeated three
  times for a 900ms illuminated sequence.
- The note's proper violin SFX plays when that illumination starts.
- There is a 200ms dark gap between notes, making each note cycle 1.1 seconds
  so its one-second audio cue finishes before the next note begins.
- After the complete pattern there is a 750ms pause, then the exact same pattern is demonstrated a second time.
- After the second demonstration, YOUR TURN begins and the held saucer ejects.
- Note inputs are locked during WATCH.

SAUCER REMINDER
- If the player returns to any saucer while the current attempt is still clean, Fiddler replays the current pattern once as a reminder.
- Correct-note progress already made in that pattern is preserved.
- The pattern is not randomized by a clean reminder.
- The four-second reminder lockout starts when WATCH finishes and the held ball
  ejects. A saucer re-entry during that window uses the normal short eject delay,
  does not replay WATCH, and does not restart the timer. A re-entry after four
  seconds replays the current pattern once and starts a new four-second lockout
  when the ball is released.

CORRECT NOTES
- A correct note plays its proper violin SFX and flashes its own shot for 1 second using the same 200ms ON / 50ms OFF burst.
- Each correct note scores 250,000 points.
- Bigger Jackpots raises every correct-note award to 300,000.
- Correct-note feedback does not lock gameplay. As soon as WATCH ends, ordered
  note hits advance immediately and the pattern can be completed as quickly as
  its switches register. A wrong note immediately ends that round, except for
  the existing one-time Shot Assist forgiveness.
- Correct-note SFX and visual feedback may overlap when ordered notes are hit
  less than one second apart. Different target lights run concurrently; a
  rapid repeat of the same target restarts that target's feedback burst.

PATTERN PROGRESSION
- The first pattern contains 1 note.
- Each successful pattern increases the pattern length by one, to a maximum of 4 notes.
- Once 4 notes is reached, later successful rounds continue with newly randomized 4-note patterns.
- Repeated note shots are allowed in a pattern.
- Completing the first pattern is enough to count Fiddler as defeated for villain progression, but the gameplay continues until the failure limit is reached.
- After every successful pattern the player must return to a saucer to start the next WATCH phase.

FAILED ROUND
- The first unassisted incorrect note in an attempt plays violin_bad_note and flashes the CORRECT shot for 1 second.
- That mistake counts as exactly one failed round.
- After a round has failed, all four note shots are inactive for progression: hitting any of them plays violin_bad_note and flashes THAT SHOT'S own light for 1 second.
- Additional note hits while the round is already failed do not add more failures.
- The player must return to a saucer to continue.
- After a failed round, the saucer starts a NEW randomized pattern with the SAME number of notes as the failed pattern.

MODE END
- Fiddler normally allows 3 failed rounds.
- More Jackpots allows a fourth failed round before the mode ends.
- The mode continues regardless of successful patterns until the failure limit is reached or the ball ends.
- If at least one pattern was completed before the failure limit, Fiddler is recorded as defeated when the mode ends.
- If the player reaches the failure limit without completing any pattern, Fiddler escapes and is recorded as failed.
- Villain/wizard modes never resume on the next ball; a drain ends the active Fiddler attempt.

CASE FILES
- More Jackpots: allows 4 failed rounds instead of 3.
- Bigger Jackpots: correct notes are worth 300,000 instead of 250,000.
- More Time: starts a 25-second ball save.
- Safety Net: starts the standard 10-second Case File ball save.
- Shot Assist: one-time mistake forgiveness. On the first wrong note, play violin_bad_note and flash the correct shot for 1 second, but do not fail the round and do not advance the pattern. The player still needs to hit the same correct note.

SUMMARY
- Mode score = all correct-note awards.
- PATTERNS = successful patterns completed.
- NOTES HIT = total correct notes scored.
