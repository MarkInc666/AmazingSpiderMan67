COMIC COLLECTED — EVENT-SCOPED SELECTOR

The single widgets/wizard_comic_summary.tscn scene contains 11 MPFConditional cover nodes.

The cover conditionals use chapter_number from the wizard_comic_summary_show
event (1..11 = comic/chapter). The event is posted with the completed wizard's
chapter number, so the correct cover is selected as the widget is created.

This replaces the delayed player-variable clear/reassert workaround, which
could leave every conditional cover hidden while the frame and COLLECTED stamp
still appeared.
