PARAFINO: MELT THE WAX

Start 2-ball multiball.

Three areas independently build lit saucer jackpots:
- Left Drops -> Saucer 1
- Pop Bumpers -> Saucer 2
- Right Drops -> Saucer 3

Every qualifying area hit:
- scores an extra 5K
- increases that area's hit count by 1
- lights the matching saucer jackpot

Jackpot value:
- 100K x area hits normally
- 150K x area hits with Bigger Jackpots
- area hits cap at 20

Shot Assist makes the first hit in each area count as two hits.

Add-a-ball:
- the matching number insert lights after 3 area hits
- More Time lights it after 2 area hits
- each area can award add-a-ball only once per Parafino mode

Collecting a lit saucer:
- awards WAX JACKPOT at the area's current value
- resets that area's hit count to 0
- awards add-a-ball when the number insert was qualified
- ejects the ball after about 2 seconds

With More Jackpots, the first collect in each area preserves the same lit jackpot value for one extra collect. The hit count and add-a-ball qualification still reset immediately after the first collect.

Safety Net starts a 10-second ball save after the initial multiball save ends.

Persistent status shows:
LEFT {hits}X  POPS {hits}X  RIGHT {hits}X

The saucer inserts show lit jackpots. Number inserts show add-a-ball readiness.

Mode ends immediately when multiball returns to one ball.

Summary:
- Mode Score
- Biggest JP
- Jackpots Collected
